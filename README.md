## 💻 Quick Start

### 1. Installation
```bash
# Install root, server, and client dependencies
npm run install:all
```

### 2. Database Seeding
```bash
npm run seed --prefix server
```

### 3. Run Development Servers
```bash
npm run dev
```
- **Frontend**: `http://localhost:3000`
- **Backend**: `http://localhost:5001/api/v1`
